## Повторение и собственная выборка

Источник: [COCO8, описание Ultralytics](https://docs.ultralytics.com/datasets/detect/coco8/), [архив](https://github.com/ultralytics/assets/releases/download/v0.0.0/coco8.zip). Сохраните изображения и YOLO-разметку в `data/evaluation/coco8`.

```powershell
python scripts/validate_model.py --dataset data/evaluation/coco8 --splits train val --name "COCO8: проверка подключения детектора" --source https://docs.ultralytics.com/datasets/detect/coco8/ --limitations "8 изображений из COCO train2017; возможно пересечение с обучением. Не промышленное испытание."
```

Для собственного набора используйте `images/test/*` и `labels/test/*.txt`, строки `class cx cy width height` с нормированными координатами. Класс человека — 0; пустой файл означает подтверждённое отсутствие людей. Отсутствующий файл разметки вызывает ошибку, а не считается отрицательным примером. Пример команды:

```powershell
python scripts/validate_model.py --dataset data/pilot --splits test --purpose independent_test --name "Участок 1: отложенная выборка" --source "Внутренняя выборка, разрешение и дата" --limitations "Укажите ракурсы и условия" --output data/pilot-report
```

Флаг `independent_test` сам по себе не делает выборку независимой: разделите записи по камерам и дням, исключите обучающие фрагменты и зафиксируйте пороги до проверки. Не перезаписывайте предыдущий протокол при сравнении моделей.
