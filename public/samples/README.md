# Тестовое видео с рабочими

`workers.mp4` — реальная съёмка двух рабочих на строительном участке. Источник: [Two construction workers, Mixkit #1436](https://mixkit.co/free-stock-video/two-construction-workers-1436/). Файл скачан 30.09.2026 с `https://assets.mixkit.co/videos/1436/1436-720.mp4`. Страница разрешает личное и коммерческое использование по [Mixkit Stock Video Free License](https://mixkit.co/license/#videoFree). Это стороннее стоковое видео, а не запись пилота HSE AI-Video. Люди и организация на видео не являются заявленными партнёрами проекта.

`workers-analysis.json` содержит результат настоящего YOLO11n + ByteTrack. `workers-analyzed.mp4` — производная версия: добавлены рамки, ID, время и поясняющие подписи, звук не переносился. `workers-poster.jpg` — кадр производной версии. Видео не использовалось для обучения модели.

Обработано 127 кадров из записи 15,79 с с частотой 8 кадров/с; декодировано 379 кадров. Получены ID 1 и 2. Это локальные идентификаторы треков, не подтверждение уникальных личностей. СИЗ и опасные зоны не анализировались. Эталонная разметка отсутствует, метрики точности не вычислялись. JSON содержит хеш исходного файла и установленной модели.

В интерфейсе «Тестовое видео» показывается исходный ролик; Canvas накладывает сохранённые результаты согласно времени воспроизведения. Перемотка и повторный просмотр не являются повторным инференсом. События не записываются в журнал рабочих камер.

Повторить реальный расчёт из корня проекта:

```powershell
python scripts/analyze_sample_video.py --input public/samples/workers.mp4 --source https://mixkit.co/free-stock-video/two-construction-workers-1436/ --title "Two construction workers" --license https://mixkit.co/license/#videoFree
```

Нужны установленные зависимости inference/ingestion, модель `models/person.onnx` и шрифт Segoe UI (Windows) или DejaVu Sans (Linux). Обработка полностью локальная. Команда обновляет MP4 с разметкой и протокол; сохраните старые результаты отдельно, если сравниваете версии модели.
