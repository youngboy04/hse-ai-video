# Подключённый детектор людей

На 30.09.2026 локально установлен `models/person.onnx`: предобученный **Ultralytics YOLO11n**, экспортированный из `yolo11n.pt`. Обучение этой модели в рамках проекта не выполнялось. Платформа использует только класс `person` (0) из 80 классов COCO.

- SHA-256 ONNX: `a219f5401fb1af4d2cb01027d8e6e500b0f5e519ffbaeccbead57c375c75de07`.
- Вход: RGB, float32, NCHW, 1×3×640×640, letterbox, значения 0…1.
- Экспорт: opset 17, batch 1, без динамических размерностей, FP32, без встроенного NMS.
- Версии экспорта: ultralytics 8.4.169, torch 2.14.0, onnx 1.23.1, onnxslim 0.1.97. Проверка: ONNX Runtime 1.30.0, CPUExecutionProvider.
- Назначение: проверка интеграции детектора и подготовка испытаний. Модель не определяет каски, жилеты или падения; не идентифицирует людей.

## Повторный экспорт

В отдельной среде установите зависимости из `requirements-export.txt`, затем выполните из корня проекта:

```powershell
python scripts/export_models.py --detector yolo11n.pt
```

Загрузка исходных весов требует сети. Рабочий инференс после установки модели выполняется локально. Повторный экспорт может изменить байтовый хеш; новый файл нужно проверить повторно. Веса исключены из Git, при переносе проекта перенесите и проверьте модель отдельно.

## Результат и ограничения

На восьми фотографиях COCO8 при confidence=0.35 и IoU=0.5: TP=4, FP=0, FN=6. Это функциональная проверка, не независимая оценка качества: COCO8 происходит из COCO train2017 и может пересекаться с обучением модели. Полный протокол: [report.json](../docs/evidence/report.json), просмотр всех изображений: [report.html](../docs/evidence/report.html).

Для пилота нужна отдельная размеченная выборка с разрешённых камер, содержащая дальние планы, перекрытия, сложное освещение и пустые сцены. До этого результаты нельзя переносить на производственный участок.
